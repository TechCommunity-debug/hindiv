हिंदी के शब्द एक जगह से नहीं आए। कुछ संस्कृत से सीधे उठा लिए गए, कुछ सदियों में घिसकर बदल गए, कुछ
इसी भूमि की बोलियों से आए और कुछ विदेशी संपर्क से। उत्पत्ति के आधार पर शब्दों का यही वर्गीकरण
**तत्सम-तद्भव** के नाम से पढ़ाया जाता है।

## 1. तत्सम शब्द

*तत् + सम* = उसके समान, अर्थात् संस्कृत के समान। जो शब्द संस्कृत से **ज्यों के त्यों** हिंदी में
आ गए, वे तत्सम कहलाते हैं।

<Udaharan items={["अग्नि", "सूर्य", "पुस्तक", "मातृ", "हस्त", "दुग्ध", "कर्ण"]} />

<Dhyan>
तत्सम शब्दों की पहचान प्रायः उनकी ध्वनियों से होती है। जिन शब्दों में *ऋ, ष, क्ष, त्र, ज्ञ,
श्र* अथवा संयुक्त व्यंजन हों, वे प्रायः तत्सम होते हैं — *ऋषि*, *भाषा*, *क्षमा*, *ज्ञान*।
</Dhyan>

## 2. तद्भव शब्द

*तत् + भव* = उससे उत्पन्न। जो शब्द संस्कृत से निकले पर समय के साथ **रूप बदलकर** हिंदी में आए, वे
तद्भव कहलाते हैं।

<Udaharan items={["आग", "सूरज", "पोथी", "माँ", "हाथ", "दूध", "कान"]} />

यह बदलाव एक ही छलाँग में नहीं हुआ। शब्द संस्कृत से पालि-प्राकृत और अपभ्रंश से होते हुए हिंदी तक
पहुँचे।

<Udaharan label="विकास क्रम">
संस्कृत **हस्त** → प्राकृत **हत्थ** → हिंदी **हाथ**

संस्कृत **अग्नि** → प्राकृत **अग्गि** → हिंदी **आग**
</Udaharan>

| तत्सम | तद्भव |
| --- | --- |
| अग्नि | आग |
| सूर्य | सूरज |
| दुग्ध | दूध |
| हस्त | हाथ |
| कर्ण | कान |
| मयूर | मोर |
| सप्त | सात |
| अष्ट | आठ |
| ग्राम | गाँव |
| क्षेत्र | खेत |
| मस्तक | माथा |
| चंद्र | चाँद |
| कार्य | काज |
| वर्षा | बरसात |
| गृह | घर |
| पत्र | पत्ता |
| मृत्यु | मौत |
| श्रावण | सावन |
| आश्चर्य | अचरज |
| उज्ज्वल | उजला |

<Dhyan>
तद्भव बनने में कुछ ध्वनि-परिवर्तन बार-बार दिखते हैं: संयुक्त व्यंजन सरल हो जाते हैं (*क्षेत्र* →
*खेत*), *र* लुप्त हो जाता है (*कर्म* → *काम*), और *ष/श* प्रायः *स* या *ख* में बदल जाते हैं
(*शुष्क* → *सूखा*)। ये नियम याद होने पर अनजान युग्म भी अनुमान से पहचाने जा सकते हैं।
</Dhyan>

## 3. देशज शब्द

जो शब्द न संस्कृत से आए, न विदेश से — बल्कि इसी क्षेत्र की बोलियों और लोकभाषा में जन्मे, वे
**देशज** कहलाते हैं। इनका मूल प्रायः खोजा नहीं जा सकता।

<Udaharan items={["पगड़ी", "लोटा", "खिड़की", "ठेठ", "कलाई", "झाड़ू", "चिड़िया"]} />

कई देशज शब्द ध्वनि के अनुकरण से बने हैं — *खटखटाना*, *भड़भड़*, *टनटन*।

## 4. विदेशी शब्द

लंबे राजनीतिक और व्यापारिक संपर्क के कारण अनेक भाषाओं के शब्द हिंदी में आकर घुल-मिल गए।

| भाषा | उदाहरण |
| --- | --- |
| अरबी | अदालत, कानून, किताब, औरत, हिसाब |
| फ़ारसी | आदमी, दुकान, कागज़, चश्मा, ज़मीन |
| तुर्की | कैंची, चाकू, तोप, बेगम, उर्दू |
| अंग्रेज़ी | स्टेशन, डॉक्टर, स्कूल, टिकट, अस्पताल |
| पुर्तगाली | आलमारी, चाबी, बाल्टी, कमीज़, तौलिया |
| फ़्रांसीसी | कारतूस, अंग्रेज़, कूपन |

## 5. संकर शब्द

जब दो भिन्न भाषाओं के शब्द जुड़कर एक नया शब्द बनाते हैं, उसे **संकर शब्द** कहते हैं।

| संकर शब्द | स्रोत |
| --- | --- |
| रेलगाड़ी | रेल (अंग्रेज़ी) + गाड़ी (हिंदी) |
| सीलबंद | सील (अंग्रेज़ी) + बंद (फ़ारसी) |
| टिकटघर | टिकट (अंग्रेज़ी) + घर (हिंदी) |
| जेबकतरा | जेब (फ़ारसी) + कतरा (हिंदी) |

## पहचान का अभ्यास

<Udaharan label="तुलना कीजिए">
**क्षेत्र** — तत्सम (संयुक्त व्यंजन *क्ष* सुरक्षित)

**खेत** — तद्भव (वही शब्द, ध्वनि सरल होकर)

**खिड़की** — देशज (बोली से आया)

**खिदमत** — विदेशी (अरबी)
</Udaharan>
