*राजा का पुत्र* कहने के बजाय हम *राजपुत्र* कह देते हैं। बीच का *का* लुप्त हो गया और दो शब्द मिलकर
एक हो गए — यही **समास** है। समास भाषा को संक्षिप्त बनाता है।

समस्त पद को तोड़कर मूल शब्दों में लिखना **समास विग्रह** कहलाता है।

| समस्त पद | समास विग्रह |
| --- | --- |
| राजपुत्र | राजा का पुत्र |
| नीलकमल | नीला है जो कमल |
| यथाशक्ति | शक्ति के अनुसार |

## पूर्वपद और उत्तरपद

समास में पहला शब्द **पूर्वपद** और दूसरा **उत्तरपद** कहलाता है। समास का भेद प्रायः इसी से तय होता
है कि इन दोनों में **प्रधान कौन** है।

| भेद | प्रधान पद |
| --- | --- |
| तत्पुरुष | उत्तरपद |
| कर्मधारय | उत्तरपद (पूर्वपद विशेषण) |
| द्विगु | उत्तरपद (पूर्वपद संख्या) |
| द्वंद्व | दोनों |
| बहुव्रीहि | कोई नहीं — कोई तीसरा अर्थ |
| अव्ययीभाव | पूर्वपद |

<Dhyan>
यही तालिका समास पहचानने की कुंजी है। भेद रटने के बजाय हर बार यही पूछिए — **प्रधान कौन है?**
</Dhyan>

## 1. तत्पुरुष समास

जिसमें **उत्तरपद प्रधान** हो और विग्रह में बीच का कारक-चिह्न लुप्त हो।

| समस्त पद | विग्रह | लुप्त कारक |
| --- | --- | --- |
| राजपुत्र | राजा का पुत्र | संबंध |
| ग्रंथकार | ग्रंथ को करने वाला | कर्म |
| तुलसीकृत | तुलसी द्वारा कृत | करण |
| देशभक्ति | देश के लिए भक्ति | संप्रदान |
| पापमुक्त | पाप से मुक्त | अपादान |
| गृहप्रवेश | गृह में प्रवेश | अधिकरण |

## 2. कर्मधारय समास

जिसमें एक पद **विशेषण** और दूसरा **विशेष्य** हो, या एक उपमान और दूसरा उपमेय।

| समस्त पद | विग्रह |
| --- | --- |
| नीलकमल | नीला है जो कमल |
| महात्मा | महान है जो आत्मा |
| चरणकमल | चरण रूपी कमल |
| चंद्रमुख | चंद्र के समान मुख |

## 3. द्विगु समास

जिसमें **पूर्वपद संख्यावाचक** हो और पूरा पद किसी **समूह** का बोध कराए।

| समस्त पद | विग्रह |
| --- | --- |
| त्रिलोक | तीन लोकों का समूह |
| नवरत्न | नौ रत्नों का समूह |
| चौराहा | चार राहों का समूह |
| पंचवटी | पाँच वटों का समूह |

<Dhyan>
**कर्मधारय और द्विगु में अंतर:** दोनों में पूर्वपद विशेषण होता है। पर द्विगु में वह विशेषण
**संख्यावाचक** होता है और पूरा पद समूह बताता है। *नीलकमल* कर्मधारय है, *नवरत्न* द्विगु।
</Dhyan>

## 4. द्वंद्व समास

जिसमें **दोनों पद प्रधान** हों। विग्रह में *और*, *तथा* या *या* आता है।

| समस्त पद | विग्रह |
| --- | --- |
| माता-पिता | माता और पिता |
| राजा-रंक | राजा और रंक |
| दिन-रात | दिन और रात |
| सुख-दुख | सुख और दुख |

<Dhyan>
द्वंद्व समास पहचानने का सरल तरीका: विग्रह में **“और”** लगाकर देखिए। यदि अर्थ पूरा बन जाए, तो
द्वंद्व है। ये प्रायः योजक चिह्न (-) के साथ लिखे जाते हैं।
</Dhyan>

## 5. बहुव्रीहि समास

जिसमें **कोई भी पद प्रधान न हो**, और दोनों मिलकर किसी **तीसरे** का बोध कराएँ।

| समस्त पद | विग्रह | किसका बोध |
| --- | --- | --- |
| दशानन | दस हैं आनन जिसके | रावण |
| नीलकंठ | नीला है कंठ जिसका | शिव |
| चक्रधर | चक्र धारण करता है जो | विष्णु |
| लंबोदर | लंबा है उदर जिसका | गणेश |
| पीतांबर | पीत है अंबर जिसका | कृष्ण |

<Dhyan>
**कर्मधारय और बहुव्रीहि में अंतर** सबसे अधिक भ्रम पैदा करता है, क्योंकि शब्द एक जैसे दिखते हैं।

*नीलकंठ* = नीला कंठ → **कर्मधारय** (कंठ की ही बात है)

*नीलकंठ* = नीला है कंठ जिसका, अर्थात् **शिव** → **बहुव्रीहि** (किसी तीसरे की बात है)

निर्णय शब्द से नहीं, **वाक्य में उसके अर्थ** से होगा। यदि पद किसी तीसरे की ओर संकेत करे, तो
बहुव्रीहि।
</Dhyan>

## 6. अव्ययीभाव समास

जिसमें **पूर्वपद अव्यय** हो और पूरा पद अव्यय बन जाए — अर्थात् उसका रूप कभी न बदले।

| समस्त पद | विग्रह |
| --- | --- |
| यथाशक्ति | शक्ति के अनुसार |
| प्रतिदिन | प्रत्येक दिन |
| आजीवन | जीवन भर |
| यथासंभव | जैसा संभव हो |
| भरपेट | पेट भरकर |

पहचान के लिए पूर्वपद देखिए — *यथा, प्रति, आ, भर, हर, बे, ला* आदि प्रायः अव्ययीभाव बनाते हैं।

## समास और संधि में अंतर

| आधार | संधि | समास |
| --- | --- | --- |
| मेल किसका | वर्णों का | शब्दों का |
| क्या बदलता है | वर्ण में विकार | कारक-चिह्न लुप्त |
| अलग करना | संधि विच्छेद | समास विग्रह |
| उदाहरण | हिम + आलय = हिमालय | राजा का पुत्र = राजपुत्र |
